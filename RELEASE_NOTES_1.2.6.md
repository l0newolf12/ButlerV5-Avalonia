1.2.6. Avalonia release.

### Highlights

- ButlerV5 is now available for VibeSkua Avalonia, with native Avalonia windows and the same follow, summon, combat, and parking behavior as the WPF version.
- The roster shows each account's currently equipped class beside its map and server. The label updates when that account changes class, including manual equips.
- Accounts running the Avalonia and WPF editions on the same PC can follow and summon each other. Both editions now use version 1.2.6.

### Other

- Build output is excluded from the source repository. Download the ready-to-install DLL from the release assets below.

### Install

1. Download `ButlerV5 Avalonia.dll` below
2. Drop it into `%APPDATA%\Skua\plugins`
3. Launch VibeSkua Avalonia and open the **Butler V5** window

Use the plugin edition that matches your client. Do not load the WPF and Avalonia DLLs together in the same client.

Client-side only - use with your own accounts and within AQW's Terms of Service.

# **Requires VibeSkua Avalonia (.NET 10 build)**
